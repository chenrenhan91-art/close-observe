# 收盘观察

给普通 A 股投资者的情绪与选股研究笔记。页面先看情绪快照与市场宽度，再按短线、中线、长线切换策略，比较候选股的上榜原因、风险与评分。

它只提供观察名单，不提供买入价、止损价、目标价或仓位，也不构成投资建议。

## 本地生成并查看

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m pipeline.build --force
npx wrangler pages dev web --port 8765
```

浏览器打开 `http://127.0.0.1:8765`。交易日 15:05 之后生成的是收盘快照；在这之前会标明盘中数据。非交易日不加 `--force` 时，脚本不会覆盖已有快照。

## 部署到 Cloudflare Pages

市场宽度使用 Cloudflare Pages 的 `web/_worker.js` 获取东方财富涨跌家数：交易时段页面在前台时每 60 秒刷新，也可手动刷新。行情可能延迟或暂时不可用，统计使用数据源的沪深京市场口径。情绪评分和选股名单使用快照。页面在前台时每 5 分钟检查一次快照，生成时间变了就换成新快照，并标示快照日期和计算口径。

每个 A 股交易日北京时间 12:30 和 15:30，GitHub Actions 生成 `web/data/snapshot.json`，再发布到 Pages 项目 `close-observe`。12:30 在收盘判定（15:05）之前，这份快照标为盘中；15:30 标为收盘。节假日和开盘前脚本不会覆盖线上快照。GitHub 可能晚几分钟才开始，构建本身也要一段时间，网站会在这两个点之后更新。此自动更新需要将项目放入 GitHub 仓库并配置工作流密钥；仅手动部署不会自动更新选股快照。

仓库需要两个密钥：

- `CLOUDFLARE_API_TOKEN`：包含 Cloudflare Pages 编辑权限
- `CLOUDFLARE_ACCOUNT_ID`

首次发布前，在 Cloudflare 里创建 Pages 项目 `close-observe`。构建失败、或者上市日期覆盖不足时，工作流不会覆盖线上文件。

价格和估值来自新浪财经，60 日涨跌幅、量比和日 K 来自腾讯财经，涨停池、财报和新闻来自东方财富。GitHub 的托管机器在海外时，东方财富有时会拒绝访问。这时在自己的电脑上生成快照，再执行：

```bash
npx wrangler pages deploy web --project-name=close-observe
```

## 六个策略

| 周期 | 策略 | 在看什么 |
| --- | --- | --- |
| 短线 | 涨停后观察 | 近 3 日进过涨停池，今天没有封死涨停 |
| 短线 | 行业活跃 | 涨幅适中、量能活跃，行业中位数涨幅靠前 |
| 中线 | 趋势中军 | 60 日趋势还在，收盘价站上 60 日均线 |
| 中线 | 业绩成长 | 最新报告期营收和利润增长，估值在区间内 |
| 长线 | 质量价值 | 盈利、负债和估值同时过线 |
| 长线 | 高股息 | 最近年报现金股息率过线，最新报告净利润同比不低于零 |

某一档筛出不足 5 只时，阈值放宽一档，并写在卡片上。依赖的整表数据抓不到时，那张名单标为不可用，不用别的数字顶上。

东方财富涨停池通常不含 ST 和科创板。页面会按当天池子里有没有科创板代码写明这一点。

## 分数

四个维度是基本面、技术面、资金面、行业位置。短线权重 45/30/15/10，中线 35/30/20/15，长线 55/15/20/10。缺数据的维度不按 0 分计入；可用权重至少 70% 且至少有两项时，才按其余权重重算总分，否则不评分。基本面须有净资产收益率和至少一项估值。评分仅用于规则筛选，未经历史回测，不表示未来收益概率。资金流排名失败时，这项改名为「成交活跃」。每张策略名单固定展示 8 只。资讯最多 8 条，只给标题、时间和原文链接。

行情和资金流每次构建重新获取；日 K 仅复用快照日收盘后生成且覆盖该交易日的缓存，盘中缓存不会作为收盘数据。交易日历过期或开盘前不会生成当日快照。财报净利润同比不以其他报告期的数据代替。
